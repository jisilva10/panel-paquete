# El motor

Todo lo que usa la rutina (paso a paso en `RECETA.md`). Python: `.motor\venv\Scripts\python` en la PC.

| Archivo | Para qué |
|---|---|
| `RECETA.md` | La rutina de las 3 a. m., paso a paso. Manda sobre todo lo demás. |
| `tarea-programada.md` | El texto de las 3 tareas programadas de la PC (se copian solas, RECETA paso 0). |
| `variables.json` | Las ~30 palancas que se prueban en cada video y sus opciones exactas. |
| `laboratorio.py` | Qué palanca gana y el plan de cada video (BASE + PRUEBAS), la hora y los temas. Lo corren los 3 videos. |
| `ganadores.py` | Resultado a 48 h dentro de cada `que-se-hizo.txt` y `3 Publicado/ganadores.md`. Lo corre el video 1. |
| `ya_hecho.py` | Que nunca se repita historia, protagonista, gancho, cierre ni título. |
| `nueva_funcion.py` | Crea `2 Funciones/NNN. Título/` con la base de la película y las plantillas. |
| `voces.py` | `voces.py CARPETA qwen <ritmo> <velocidad>` → la voz con la boca y los tiempos de cada palabra. |
| `portada.py` | `portada.py ESCENA.png "ARRIBA" "ABAJO" portada.jpg [limpio.png]` → portada con las dos placas. |
| `palancas.py` | Copia las palancas de `etiquetas.json` al `que-se-hizo.txt` y avisa si un valor no cuadra. |
| `limpiar.py` | Al final: copia las palancas y deja solo textos + `video.mp4` + `portada.jpg`. |
| `revisar.py` · `revisar_celeste.py` | Que esté todo instalado · que el video no tenga cuadros vacíos. |
| `base/` | La película de ejemplo (la guerra de los emús): mundo de papel, títeres, cámara, foto y clip reales, mezcla. |
| `plantillas/` | `guion.txt` y `que-se-hizo.txt` vacíos. |
| `sonidos/` · `musica/` · `fuentes/` | Efectos y música de Pixabay (ver `sonidos/CREDITOS.txt`) y tipografías. El «braam» se borró (JIS: suena durísimo). |
| `viejo/` | Pruebas del principio. No va a GitHub ni se usa. |
